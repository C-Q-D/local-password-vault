## 可复现构建

```powershell
npm ci
npm run build
cargo test --workspace
npm run tauri build
```

安装包生成到 `target/release/bundle/nsis/`。`target/`、`dist/`、运行数据和测试数据均由 `.gitignore` 排除，不作为源码提交。

## 安装与升级

1. 关闭正在运行的 Local Password Vault。
2. 从本仓库 GitHub Release 下载 Windows x64 `Setup.exe`。
3. 核对 SHA-256 后运行安装程序。
4. 首次启动后确认账号管理界面可以打开。

后续同一标识符版本可以覆盖安装。升级前不要手工删除应用数据目录；安装包和程序文件不是密码库数据备份。

## 数据、备份与恢复

- 密码库、上一版备份和进程锁位于 Tauri 为 `com.localpasswordvault.desktop` 分配的当前用户应用数据目录。
- 主文件和备份都是 AES-256-GCM 加密文件，数据密钥由当前 Windows 用户的 DPAPI 保护。
- 主文件损坏而上一版有效时，程序只在用户明确确认后恢复。
- 无法通过单独复制加密文件实现跨 Windows 用户或系统重装恢复；需要同时具备原 Windows 用户的 DPAPI 环境或完整系统备份。

## 回滚

v0.1.0 是首个 GitHub Release，没有更早的安装包可回退。发生严重问题时：

1. 立即退出程序，保留应用数据目录，不继续写入。
2. 卸载程序文件时不要删除密码库数据。
3. 从 Git 标签 `v0.1.0` 可重新构建相同版本；若数据进入恢复状态，只使用程序提供的确认恢复流程。
