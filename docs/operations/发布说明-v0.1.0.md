# Local Password Vault v0.1.0

首个 Windows 可安装版本，面向个人本机账号与密码管理。

## 功能

- 分类的创建、重命名、过滤和安全删除。
- 账号的新增、编辑、删除、搜索与最近使用排序。
- 密码默认隐藏，账号名和密码独立复制。
- 近 7 天、近 1 个月、近半年和近 1 年使用概览。
- 字体类型、字号设置，以及内置项目架构与加密原理说明。

## 数据保护

- AES-256-GCM 整库加密和完整性校验。
- Windows DPAPI 保护随机数据密钥。
- 独占进程锁、同目录原子替换和上一版加密备份。
- 密码剪贴板使用所有权凭证，在 30 秒后条件清理。

## 当前限制

- 仅支持 Windows 10/11 x64。
- DPAPI 绑定当前 Windows 用户，不支持只复制密码库文件进行跨机恢复。
- 不包含云同步、导入导出、浏览器自动填充、移动端或 macOS 版本。
