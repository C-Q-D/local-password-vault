## 已知限制

- 安装包未进行数字签名，Windows SmartScreen 可能显示来源提示。
- 本次验证启动了 Release 主程序，但没有在当前开发机执行安装和卸载，以免改变现有安装状态。
- DPAPI 数据密钥只对创建密码库的 Windows 用户有效；v0.1.0 不支持跨电脑、系统重装或其他 Windows 用户恢复。
- macOS、云同步、导入导出、浏览器自动填充和移动端不在本版本范围内。
