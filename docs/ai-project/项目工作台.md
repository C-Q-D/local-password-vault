## 项目定义

- 核心问题：个人需要在 Windows 本机集中保存、分类、查找和复制多个网站账号密码。
- 目标用户：项目所有者本人。
- 项目目标：提供一个无需联网、启动后可直接管理账号的轻量桌面 App。
- 成功结果：用户可以可靠地分类和维护多个账号，重启 App 后数据仍然存在且互不覆盖。
- MVP：分类管理、账号增删改查、同站点多账号、搜索、密码隐藏与复制、本地持久化。
- 明确不做：云同步、在线账号体系、浏览器插件、网页自动填充、手机端、多人共享、泄漏检测、标签、附件、导入导出和独立设置页。
- 核心流程：启动 App → 选择或创建分类 → 新增或查找账号 → 查看、编辑或复制字段 → 自动保存到本地。

详细定义见[产品定义](../product/产品定义.md)。

## 决定与变更

| 日期 | 决定或变更 | 原因 | 影响 |
|---|---|---|---|
| 2026-08-29 | 分类由用户创建；非空分类禁止删除 | 避免分类删除导致账号归属变化或误操作 | 增加删除前数量校验和错误提示 |
| 2026-08-29 | 同一网站允许保存多个账号 | 用户在 GitHub 等站点存在多个身份 | 账号名和地址不设置唯一限制 |
| 2026-08-29 | 账号字段固定为账号名、密码、地址、邮箱和备注 | 保持本地密码本的最小功能范围 | 账号名和密码必填，其余可空 |
| 2026-08-29 | App 启动后直接进入账号管理 | 本机个人使用情境 | 主界面作为启动入口 |
| 2026-08-30 | 选择 Rust stable、Tauri 2、Svelte、TypeScript 和 Vite | 项目所有者选择 Rust，并希望复用 Windows/macOS 界面和 Tauri 生态 | 使用系统 WebView；平台密钥、路径和剪贴板保持隔离 |
| 2026-08-30 | 独立维护 Rust/Tauri 编译策略 | 避免每次修改都执行耗时的全量或 Release 编译 | 代码和测试变更在编译前必须读取 `docs/development/编译策略.md` |
| 2026-08-29 | 使用加密单文件而非数据库 | 个人规模可在内存中快速搜索，整库原子保存减少依赖和迁移复杂度 | JSON 经 AES-GCM 加密，DPAPI 保护数据密钥 |
| 2026-08-29 | 恢复范围限定在同一 Windows 用户配置 | 无主密码意味着没有独立于 Windows 用户的恢复凭据 | 第一版不支持跨机或系统重装恢复 |
