## 路线依据

项目只有单一 Windows 桌面 App，无服务器、无外部 API、仅供个人使用，需求与运行负担较低；但持久化数据是现实账号密码，数据敏感度达到完整路线门槛。流程深度只加强数据保护、故障保存与恢复相关部分，不扩张业务功能。
