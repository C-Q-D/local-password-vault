# Local Password Vault 产品需求

## 1. 文档范围

本文描述第一版本机 Windows 账号密码管理 App 的用户可见功能、业务规则、状态和验收标准。技术栈、文件格式和加密实现不属于本阶段。

## 2. 用户与使用情境

唯一用户是电脑所有者本人。App 不区分角色，不提供在线账号体系。用户启动 App 后直接进入账号管理主界面，并在本机完成全部操作。

## 3. 功能需求

### FR-01 启动与主界面

- App 启动后直接进入账号管理主界面。
- 主界面至少展示分类区域、账号列表、账号详情和搜索入口。
- 当没有任何账号时，界面展示空状态和新增账号入口。

验收：AC-01。

### FR-02 分类管理

- 用户可以创建分类，分类名称不能为空。
- 用户可以重命名分类。
- 用户可以删除空分类。
- 删除分类前必须检查该分类下的账号数量。
- 分类下存在一个或多个账号时，禁止删除，并提示用户先处理分类内账号。
- “全部”和“未分类”是系统视图，不能重命名或删除。

验收：AC-02、AC-03。

### FR-03 账号字段与校验

每条账号记录只包含：

| 字段 | 规则 |
|---|---|
| 账号名 | 必填 |
| 密码 | 必填，默认隐藏 |
| 地址 | 可空 |
| 邮箱 | 可空 |
| 备注 | 可空 |

- 账号名或密码为空时禁止保存，并在对应字段附近显示明确提示。
- 地址和邮箱不要求格式校验，避免阻止用户记录非标准账号信息。

验收：AC-04。

### FR-04 同一网站多个账号

- 账号名、地址和邮箱均不设置唯一约束。
- 多条记录可以使用相同地址。
- 新增、修改或删除其中一条记录，不得覆盖或改变其他记录。

验收：AC-05。

### FR-05 账号管理

- 用户可以新增、查看、编辑和删除账号。
- 账号可以属于一个用户分类，也可以处于“未分类”。
- 用户可以把账号移动到其他分类或“未分类”。
- 删除账号前必须显示确认提示。
- 保存成功后，列表和详情立即显示最新内容。

验收：AC-06、AC-09、AC-10。

### FR-06 搜索

- 搜索范围包括账号名、地址、邮箱和备注。
- 搜索不匹配密码字段。
- 选择“全部”时搜索所有账号；选择用户分类或“未分类”时只搜索当前范围。
- 搜索无结果时显示明确空状态。

验收：AC-07。

### FR-07 密码查看与复制

- 密码默认隐藏。
- 用户可以临时显示或再次隐藏密码。
- 用户可以复制账号名和密码。
- 复制密码后，App 在固定时间内尝试清除由本 App 写入的剪贴板内容；第一版固定为 30 秒。

验收：AC-08。

### FR-08 本地保存

- 新增、修改、删除和分类变更成功后自动保存到本机。
- App 不依赖网络；断网不影响正常使用。
- 保存失败时显示明确错误，不得把失败状态伪装成保存成功。
- 保存失败不得破坏上一次成功保存的数据。
- App 不在普通日志中输出账号名、密码、邮箱、备注或其他记录内容。

验收：AC-09、AC-10。

## 4. 用户可见状态

| 状态 | 用户看到的结果 |
|---|---|
| 初次使用或无账号 | 空状态、分类区域和新增账号入口 |
| 分类为空 | 当前分类无账号的提示 |
| 搜索无结果 | 当前搜索没有匹配账号的提示 |
| 必填字段为空 | 对应字段校验提示，记录不保存 |
| 删除非空分类 | 删除被阻止，并提示先处理分类内账号 |
| 删除账号 | 先显示确认提示，确认后执行 |
| 保存失败 | 显示失败原因或可理解提示，保留上次成功数据 |
| 本机离线 | 所有第一版功能照常使用 |

| AC-03 | FR-02 | 非空分类删除被阻止并提示 |
| AC-04 | FR-03 | 必填和可选字段规则正确 |
| AC-05 | FR-04 | 相同地址的多个账号互不覆盖 |
| AC-06 | FR-05 | 账号完整增删改查和分类变更可用 |
| AC-07 | FR-06 | 搜索范围正确且不搜索密码 |
| AC-08 | FR-07 | 密码隐藏、复制和剪贴板清理可见 |
| AC-09 | FR-05、FR-08 | 重启后数据与上次成功保存一致 |
| AC-10 | FR-05、FR-08 | 保存失败有提示且不损坏旧数据 |
