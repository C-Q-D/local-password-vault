## 总体计划

- 产品结果：用户在账号编辑弹框中点击“删除账号”，经过独立确认后永久删除指定账号；取消时不发生任何写入。
- 验收场景：取消确认后账号不变；确认后目标账号从列表消失且分类数量同步；同地址账号保留；保存失败时旧账号仍在；重启后已删除账号不恢复。
- 明确排除：回收站、撤销、批量删除、搜索、凭据复制和整体视觉调整。
- 已确认架构：核心层只按稳定 UUID 删除；应用层从当前确认文档克隆候选并只在磁盘确认后发布；Tauri command 只接收账号 ID；前端复用现有紧凑确认框样式。
- 全局不变量：不得按列表位置、地址或账号名删除；响应和日志不得返回被删密码；失败不改变 revision、确认快照和界面列表；提交中禁止重复删除。
- 执行模式：连续执行，三个原子分别验证、提交并同步。
- 整体回归：`cargo test --workspace`、`cargo check -p local-password-vault`、`npm run check`、Tauri Debug 启动冒烟；不执行 Release。
