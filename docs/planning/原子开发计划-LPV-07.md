## 总体计划

- 产品结果：用户点击账号行后，在与新增一致的弹框中编辑账号名、密码、地址、邮箱和备注；取消不修改，保存后持久化并刷新列表。
- 验收场景：弹框自动填入当前字段；清空账号名或密码时拒绝保存；修改目标账号不影响同地址的其他账号；重启后仍为新值。
- 明确排除：修改分类归属、删除账号、搜索、复制密码、列表常驻明文密码和整体视觉重做。
- 已确认架构：核心层按稳定 UUID 更新；应用层只发布磁盘确认快照；显式点击账号行后由专用 command 返回该账号编辑所需详情；列表 DTO 始终不含密码。
- 全局不变量：读取和错误日志不得输出账号字段；编辑请求不能修改 ID 或 categoryId；失败不改变已确认状态；每次成功只增加一次 revision。
- 执行模式：连续执行，三个原子分别验证、提交并同步。
- 整体回归：`cargo test --workspace`、`cargo check -p local-password-vault`、`npm run check`、Tauri Debug 冒烟；不执行 Release。

## LPV-07-01 按稳定 ID 更新账号字段候选

- 状态：in_progress
- 支持的验收场景：只修改指定账号字段；清空必填被拒绝；同地址另一账号不变。
- 唯一目标：`vault-core` 增加不改变 ID 和分类归属的账号字段更新行为。
- 当前行为与目标行为：账号只能创建；完成后可按 UUID 更新 username、password、address、email、notes。
- 前置条件与依赖：LPV-05-01。
- 代码定位依据：`crates/vault-core/src/vault.rs` 的账号创建输入、账号模型和测试。
- 允许修改：更新输入、领域行为、错误和单元测试。
- 明确不修改：category_id、持久化、Tauri、前端和删除。
- 实现步骤：先校验必填；按 UUID 定位；一次替换五个字段；保留 ID/category_id；任何失败不修改候选。
- 接口、数据与错误契约：未知 ID、账号名必填、密码必填为稳定错误；错误不回显字段值。
- 边界与异常：不按地址或账号名定位；重复地址合法。
- 测试要求：所有字段更新；ID/分类不变；未知 ID和空白必填拒绝；其他账号不变。
- 验证命令：`cargo test -p vault-core update_account`；`cargo check -p vault-core`；格式与差异检查。
- 预期结果：纯领域编辑规则可独立验证。
- 完成判定：测试证明目标唯一且失败不修改候选。
- 交付给下一原子的输出：应用层可调用的字段更新能力。
- 停止或重新规划条件：更新必须同时改变分类归属。
- 风险等级：L1
- DDD 门禁：不触发。
- 计划提交信息：`feat(core): [LPV-07-01] 支持更新账号字段候选`

## LPV-07-02 暴露账号编辑安全契约

- 状态：pending
- 支持的验收场景：显式打开编辑时取得当前字段；保存一次持久化；失败保持旧快照。
- 唯一目标：通过应用层和 Tauri/TypeScript 边界提供按 ID 读取编辑详情及提交字段更新的专用契约。
- 当前行为与目标行为：前端只有安全列表；完成后可在用户明确选择一个账号时短暂取得编辑详情并提交更新。
- 前置条件与依赖：LPV-07-01、LPV-05-02/03。
- 代码定位依据：`crates/vault-app/src/lib.rs`、`src-tauri/src/commands/vault.rs`、`frontend/src/lib/tauri/commands.ts`。
- 允许修改：应用读取/更新用例、专用详情 DTO、command、TS 类型与调用、对应测试。
- 明确不修改：列表 DTO、分类移动、删除和 Svelte 界面。
- 实现步骤：按 ID 读取一条编辑详情；按 ID 克隆候选并更新；revision 加一；保存重验后发布；注册读取与更新 command。
- 接口、数据与错误契约：详情只在显式 command 响应返回一条账号的六个表单字段；列表仍无 password/notes；请求不能更改 ID/categoryId；未知 ID 使用稳定错误。
- 边界与异常：保存失败返回错误且旧快照不变；普通日志不记录请求或响应。
- 测试要求：读取目标详情；未知 ID；更新目标而其他账号不变；必填和存储失败回滚；列表 DTO 无密码。
- 验证命令：应用/Tauri 定向测试；`cargo check -p local-password-vault`；`npm run check`；格式检查。
- 预期结果：前端具备最小账号编辑 IPC，明文密码不进入列表常驻状态。
- 完成判定：Rust/TS 契约一致且测试覆盖安全边界和失败回滚。
- 交付给下一原子的输出：Svelte 可调用的 load/update 函数。
- 停止或重新规划条件：编辑详情会被并入全量列表或写入日志。
- 风险等级：L3
- DDD 门禁：实现前质疑“明文密码只在用户显式编辑一条账号时返回，且不进入列表 DTO或日志”。
- 计划提交信息：`feat(app): [LPV-07-02] 暴露账号编辑安全契约`
