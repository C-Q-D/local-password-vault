## 总体计划

- 产品结果：用户输入账号名、地址、邮箱或备注片段时立即看到当前分类范围内的匹配账号；清空搜索恢复当前范围全部账号。
- 验收场景：四个允许字段均可不区分大小写包含匹配；只输入密码或分类名称不能命中；全部、用户分类和未分类范围正确；快速输入不显示旧结果；无结果显示搜索空状态；新增、编辑和删除后结果立即同步。
- 明确排除：模糊评分、高亮、搜索历史、高级过滤、排序改造和整体视觉调整。
- 已确认架构：`vault-core` 在已确认内存文档中搜索并返回不含密码/备注的安全结果；应用层只读且不增 revision；Tauri command 接收 query 与判别式范围；Svelte 以请求代次丢弃迟到响应。
- 全局不变量：搜索实现不得读取 password 或分类名称；响应类型不得包含 password/notes；未知分类范围返回稳定错误；搜索不写盘、不改变 revision；空查询直接使用最新完整安全快照。
- 执行模式：连续执行，三个原子分别验证、提交并同步。
- 整体回归：`cargo test --workspace`、`cargo check -p local-password-vault`、`npm run check`、Tauri Debug 启动冒烟；不执行 Release。

## LPV-10-01 在确认文档中搜索安全账号结果

- 状态：done
- 唯一目标：`vault-core` 按 query 和 All/Uncategorized/Category(UUID) 范围返回安全账号结果。
- 允许修改：搜索范围、结果类型、错误、领域行为和单元测试。
- 明确不修改：应用层、持久化、Tauri、前端、模糊搜索和排序。
- 实现步骤：先验证分类范围；规范化 query；按范围过滤；仅对 username/address/email/notes 做小写包含匹配；映射为不含密码和备注的结果并保持原顺序。
- 错误契约：未知分类返回分类不存在；空 query 返回范围内全部；空可选字段不匹配非空 query。
- 测试要求：四字段、大小写、密码-only、分类名称-only、三种范围、空 query、无结果及结果结构字段。
- 验证命令：`cargo test -p vault-core search_accounts`；`cargo check -p vault-core`；格式和差异检查。
- 风险等级：L3。
- DDD 门禁：实现前隔离质疑“搜索所有可达匹配路径都不会读取或返回密码字段”。
- 计划提交信息：`feat(core): [LPV-10-01] 支持安全账号搜索`

### 执行记录

- 实际验证：四字段、大小写、密码和分类名排除、三种范围、空查询、无结果及未知分类共 2 项定向测试通过；`cargo check -p vault-core`、格式和差异检查通过。
